# Origem desta skill

Cópia sem alterações de `skills/animate-ui` do repositório https://github.com/imskyleen/animate-ui
(commit `9873c62`, release 2.4.6 do `@animate-ui/react`), trazida para o repositório para que as
sessões na nuvem a carreguem sem instalação.

- Licença: MIT + Commons Clause (`LICENSE.md`). Uso em aplicação é livre; não vender nem
  redistribuir os componentes em si. `NOTICE.md` traz os créditos (Emil Kowalski, MIT).
- Para atualizar: substituir a pasta pela versão nova do repositório de origem e ajustar o commit acima.
- Neste projeto (sem shadcn/ui, Radix, Base UI nem React Aria) o caminho aplicável é o **C**
  (animar com `motion`, tokens e primitivos próprios do Animate UI). Os caminhos A/B (CLI `animate`,
  troca de import) não se aplicam.
